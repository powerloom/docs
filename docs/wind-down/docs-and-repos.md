## Current Status

As of the announcement on June 15, 2026, all GitHub repositories under [github.com/powerloom](https://github.com/powerloom) have been made public and archived.

The documentation site ([docs.powerloom.io](https://docs.powerloom.io)) remains online.

## GitHub Repositories

- All repositories under [github.com/powerloom](https://github.com/powerloom) are now public and archived.
- Archived repositories remain readable and forkable but will not accept new issues or pull requests.
